About the Camp

Where Motivated Young Coders Level Up

CraftOfCoding Summer Camp is a free, two-week intensive designed to take motivated young learners beyond the basics. We believe every student deserves access to rigorous computer science education — regardless of background or prior experience.

Over 10 days of live, interactive sessions, students gain real skills in beginner Python, explore competitive programming through USACO preparation, and build actual websites with HTML, CSS, and JavaScript — four languages and disciplines across two weeks.

Our three instructors are qualified middle school students themselves — bringing a peer perspective, genuine enthusiasm, and real coding chops to every session.

Sessions are structured around hands-on problem-solving — students write real code from day one. Zoom is required to attend live sessions, and students will use Pycharm or a browser-based editor

What You'll Learn

The Curriculum

Every session is hands-on. Students write real code, build real projects, and solve real problems from day one.

Week Topic Description
Week 1–2
Beginner Python
An introduction to programming through Python — covering variables, conditionals, loops, functions, and basic data structures. Students write their first real programs from day one and build confidence through small, hands-on exercises each session.
Week 1–2
Competitive Programming & USACO Prep
Algorithmic thinking, problem decomposition, greedy algorithms, and USACO Bronze-level problem sets. Students learn to read, analyze, and solve structured programming challenges efficiently.
Week 1–2
Web Development
HTML document structure, CSS layouts and styling, and JavaScript interactivity. Students leave camp with a working personal website built entirely from scratch.
Daily
Problem Solving
Debugging strategies, logical decomposition, and developing the systematic thinking that underlies all software engineering — regardless of language or platform.
Daily
Hands-On Projects
Every concept is reinforced with a concrete mini-project. Students build games, tools, and web pages that they own and can continue developing after camp ends.
